# Cancellation Policy

## Order Cancellation
Customers may cancel an order only when cancellation is available for that order status.

## Before Processing
If cancellation is available before the order enters processing, the customer can use the cancellation option provided in the app.

## After Processing
Once an order has progressed beyond the available cancellation stage, cancellation may no longer be possible.

## Cancellation Charges
Any applicable cancellation charge is shown to the customer according to the order status and applicable policy.

## Refund After Cancellation
If payment was already made and a refund is applicable after cancellation, it is processed according to the applicable refund process.

## General Rule
Customers should check the cancellation option in the app or contact support if they need assistance with an order cancellation.
